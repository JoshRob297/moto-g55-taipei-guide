# Contributing to Moto G55 5G Technical Guide

Contributions to improve partition maps, unbrick scripts, and firmware compatibility are welcome.

## Guidelines
1. **Confidentiality & Privacy:** Never commit real device IMEIs, serial numbers, personal tokens, or proprietary DRM keys.
2. **Testing:** Test fastboot commands and scripts on hardware before submitting pull requests.
3. **No Commercial MDM Bypasses:** Keep all contributions strictly framed under open-source carrier debloating and legitimate device unbricking.
